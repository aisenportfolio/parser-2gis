# Парсер 2ГИС

Поиск клиентов в 2ГИС: любой город России, любая ниша, фильтры и поиск ЛПР в отзывах.

## Скачать

**[Parser2GIS.exe — последняя версия](../../releases/latest/download/Parser2GIS.exe)** (Windows 10/11, ~53 МБ)

1. Скачай `Parser2GIS.exe` и запусти. Python и другие программы ставить не нужно.
2. Если Windows покажет «Система Windows защитила ваш компьютер»: **Подробнее → Выполнить в любом случае**.
3. Для удобства закрепи на панели задач или сделай ярлык на рабочем столе.

## Как пользоваться

1. Введи **город** и **нишу** (как в поиске 2ГИС), при желании — минимальный рейтинг и число отзывов.
2. Нажми **«Собрать»**. Откроется окно Edge — его не закрывай, через него идёт сбор.
3. Если 2ГИС покажет капчу — реши её в окне Edge, сбор продолжится сам.
4. Отфильтруй результат и нажми **«Скачать Excel (CSV)»**.

**Фильтры:** рейтинг, число отзывов, доля негатива, есть/нет сайта (визитки 2ГИС, VK и Taplink сайтом не считаются),
WhatsApp, Telegram, MAX, VK, Instagram, почта, телефон, только с ЛПР, только без сетей.

**Кому писать (заточено под продажу сайтов с онлайн-записью):** у каждой компании вердикт
🔥 писать первым / 🟡 можно / ⚪ мало поводов / ⛔ не тратить время — и причины простыми словами:
нет сайта, сайт без онлайн-записи или не под телефон, жалобы клиентов «не дозвониться / не записаться»
(с цитатами из отзывов), на негатив не отвечают, свежие отзывы хуже старых, владелец конфликтует в отзывах.
Кнопка **«Скопировать сообщение»** — готовый первый абзац под найденную боль, с именем ЛПР.
**Статусы** (написали → ответили → созвон → клиент / отказ) и заметки сохраняются и видны во всех сборах.

**ЛПР:** в отзывах и ответах компании ищутся упоминания вроде «руководитель Токарев Алексей»,
«главный врач Цветков Юрий Андреевич». Рядом показывается цитата-источник.

**Советы**
- Вкладок браузера — 2 (максимум 3). Больше — 2ГИС начинает тормозить и сбор падает.
- Сбор прервался? Запусти тот же город и нишу ещё раз — проверенные карточки повторно не открываются.
- Скорость ~3–4 секунды на компанию: 100 компаний ≈ 5–7 минут.

Данные хранятся на компьютере: `%LOCALAPPDATA%\Parser2GIS\results`.

## Для разработчика

```
pip install -r requirements.txt
python app.py      # приложение в окне
python server.py   # то же в браузере, http://127.0.0.1:8765
build.bat          # собрать dist\Parser2GIS.exe
```
